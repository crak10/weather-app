# 🌤️ Clima App - Portafolio

Una aplicación web moderna y minimalista para consultar el clima actual de cualquier ciudad del mundo. Este proyecto fue desarrollado como parte de mi portafolio para demostrar habilidades en el desarrollo frontend utilizando tecnologías web nativas.

## 🚀 Demo en vivo
Puedes ver el proyecto funcionando aquí: [ENLACE_A_TU_GITHUB_PAGES]

## 🛠️ Tecnologías Utilizadas
*   **HTML5**: Estructura semántica.
*   **CSS3**: Diseño responsivo (Mobile-first), variables CSS, animaciones y efecto **Glassmorphism**.
*   **Bootstrap 5**: Utilizado vía CDN para el sistema de grid, utilidades y componentes base.
*   **Bootstrap Icons**: Iconografía del proyecto vía CDN.
*   **JavaScript Vanilla**: Lógica de la aplicación sin frameworks (ni React, ni Vue).
*   **Fetch API & Async/Await**: Consumo asíncrono de la API.
*   **OpenWeatherMap API**: Servicio externo para obtener los datos meteorológicos.

## ✨ Características Principales
*   **Buscador de ciudades**: Consulta el clima en tiempo real de cualquier parte del mundo.
*   **Diseño moderno**: Interfaz limpia con fondo animado y una tarjeta central con efecto de cristal (Glassmorphism).
*   **Manejo de estados**: 
    *   **Loader**: Indicador visual mientras se consulta la API.
    *   **Manejo de errores**: Mensajes amigables si la ciudad no existe o si hay problemas de conexión.
*   **Métricas mostradas**: Temperatura (°C), estado del clima (con ícono dinámico), humedad (%) y velocidad del viento (km/h).
*   **100% Responsive**: Optimizado para verse perfecto en dispositivos móviles y escritorio.
